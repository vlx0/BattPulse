# BattPulse

**Живая батарея.** Процент, зарядка или розетка, сколько осталось и износ — без Параметров Windows.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 9 — «Мониторинг»** · день 61.

Пятница 23 октября пропущена — этот день закрывает её.

---

## Возможности

- ватты справа сверху: с батареи (система) или NVIDIA GPU, если розетка и нет датчика PSU
- заряд 0…100 %
- розетка / батарея / зарядка
- оставшееся время, если Windows его считает
- две полоски: заряд сейчас и максимум (полная ёмкость после износа), % и мА·ч
- график последних минут
- на ПК без аккумулятора честно пишет «батареи нет»
- только Win32 + WMI, без pip

## Установка

```powershell
git clone https://github.com/vlx0/BattPulse.git
cd BattPulse
pythonw run_battpulse.pyw
```

Или `start.bat`.

Нужен Windows 10+ и Python 3.10+. Внешних зависимостей нет.
